## ⚙️ Build Setup (Xcode + CMake)

This project uses **CMake** to generate an **Xcode workspace**.

### 🔁 One-Time Setup

```bash
# From the root of the repo
rm -rf xcode-build
cmake -G Xcode -S . -B xcode-build
open xcode-build/algorithms-cpp.xcodeproj
```
🛠 How to Build

In Xcode:
* Choose the correct scheme: algorithms-cpp (for app) or tests (for unit tests)
* Press `⌘B` to build
